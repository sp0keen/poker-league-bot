# 🃏 Poker League Bot

Telegram-бот для домашней покерной лиги: организация турниров, банковский расчёт фишек, живая турнирная таблица, рейтинг игроков и статистика — без ручного учёта на бумажке.

Построен на [Telegraf](https://telegraf.js.org/) (Node.js) и [better-sqlite3](https://github.com/WiseLibs/better-sqlite3).

## Запуск

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, CHANNEL_ID
npm start
```

## Возможности

### Организация турнира
- **Калькулятор фишек** — по любому набору номиналов (свой набор фишек, не обязательно "круглый") точно считает стартовый стек на N игроков через оптимальный перебор (bounded-knapsack), а не наивную раздачу.
- **Настройки турнира перед стартом** — длина уровней (ровные по 20 мин или с ускорением: 4 уровня по 20, 4 по 15, дальше по 12) и анте (опция для быстрой игры: анте = большой блайнд, платит игрок на BB, появляется со 2-го уровня).
- **Сетка блайндов с плавным ростом** — ×1.25–2 за уровень вместо удвоения, и каждый блайнд ставится одной-двумя фишками (для стандартного набора сетка подобрана вручную: 5/10 → 10/20 → 15/30 → 25/50 → 50/100 → 75/150 → …, для своего набора строится из круглых чисел). Номинал уходит из игры, когда больше не нужен ни для одного блайнда/анте (пятёрки — на 25/50), и возвращается в игру ×100, когда большой блайнд дорастает до его новой ценности.
- **Таймер уровней** — стартует вместе с игрой; в закреплённом сообщении бот раз в 5 секунд обновляет уровень, оставшееся время, текущие и следующие блайнды и время до закрытия re-entry. По окончании уровня блайнды повышаются сами, бот присылает новую панель стола. Есть пауза; уровень можно переключить и вручную, отмена возвращает прежний остаток времени. Время хранится как момент окончания уровня, поэтому перезапуск бота таймер не сбивает.
- **Re-entry** — до 2 на игрока за игру, открыт до конца уровня 150/300 (на своём наборе — пока BB не больше 30 стартовых BB); авто-запрет, когда физически не хватает фишек в наборе.
- **Добавление игрока в процессе турнира** (late registration) — стек новому игроку собирается из фактического остатка набора (как re-entry, а не клон стартового стека); банк, призовые и очки за место автоматически пересчитываются под новое число игроков.
- **Knockouts и результаты** — фиксация выбывших, включая вариант «без knockout» (слил банк без явного оппонента — knockout никому не засчитывается), авто-расчёт призовых (банк делится по местам) и турнирных очков по фиксированной таблице на 4–10 игроков (1-е место — число игроков + 2, последнее — от −1 до −3 в зависимости от размера стола: чем больше стол, тем дороже и победа, и вылет первым).

### Во время игры
- **Живая турнирная таблица** — место, очки, приз, re-entry и knockouts обновляются в реальном времени; ещё играющие видят частично набежавший счёт, а не глухой прочерк.
- **Хронология событий** — кто кого выбил, когда докупился, когда сменился уровень блайндов и когда кто-то присоединился к турниру, с таймингом от старта.
- **Мультистольность** — несколько турниров идут параллельно; не участвующие в конкретном столе могут зайти и посмотреть его вживую (read-only), не мешая игре.
- **Отмена последнего действия** — если организатор ошибся, нажатие отменяется без пересчёта всего стола заново.

### Статистика и рейтинг
- **Общий рейтинг лиги** — сортируется по очкам, победам, нокаутам, среднему баллу за игру или выигрышу (фишки/₽); показывает изменение места (рейтинг-дельта) после каждой игры и уровень/титул рядом с именем.
- **Личный кабинет игрока** (`/me`) — статистика, лучший результат, история игр.
- **Динамические титулы** — 11 переходящих титулов лиги. 9 из них — рекорды за карьеру (больше всех нокаутов, лучший средний балл и т.д.): держит титул ровно один человек, при равенстве остаётся у того, кто добрался до значения раньше, новый претендент забирает титул только строго превзойдя текущий рекорд. Два титула («Бык»/«Медведь») — про текущую форму, а не рекорд навсегда: показывают, кто сильнее всех вырос/упал в рейтинге по итогам последнего сыгранного турнира лиги (среди тех, кто в нём участвовал), и пересчитываются заново после каждой игры. Показывается рядом с именем в рейтинге и в протоколе.
- **Достижения** — 10 разовых ачивок (первая победа, победа без единой докупки, три победы подряд и т.д.), разблокируются один раз и остаются навсегда; одинаковые ачивки нескольких игроков за одну игру группируются в одну строку.
- **Head-to-head** — у каждого игрока в профиле виден его личный «заклятый враг» (кто выбивал чаще всех) и «личная жертва» (кого выбивал он сам).
- **Справочник «Уровни, титулы и достижения»** — полный список уровней лиги, всех титулов с текущими держателями и всех ачивок с описанием.
- **Протокол турнира** — красиво оформленная итоговая таблица с титулами игроков, публикуется в Telegram-канал лиги (если подключён); внизу — новые достижения и смены титулов, если что-то из этого произошло именно в этой игре.
- **Подтверждение результатов** — если турнир завёл не владелец лиги, результат публикуется только после подтверждения владельцем (защита от случайных/ошибочных данных).

### Резервное копирование
- `/backup` — владелец в любой момент получает в личку архив со всеми данными бота (игроки, турниры, результаты, активные столы).
- `/restore` — восстановление из архива с явным подтверждением (перед перезаписью бот сам присылает бэкап текущего состояния — на случай ошибки).
- Автоматический бэкап в личку владельцу после **каждого** завершённого турнира — история переписки с ботом сама по себе является цепочкой точек восстановления.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/newgame` | организатор | начать новый турнир |
| `/rating` | все | общий рейтинг лиги |
| `/me` | все | личная статистика |
| `/history` | все | сыгранные игры: все турниры или только свои |
| `/backup` | владелец | скачать полный бэкап данных |
| `/restore` | владелец | восстановить данные из бэкапа |
| `/help` | все | список доступных команд |

Основное управление — через кнопки в главном меню и на панели активного стола, а не текстовые команды.

## Архитектура

```
index.js           — весь бот: сцены, кнопки, экраны, бизнес-логика турнира
db.js              — SQLite-слой: игроки, игры, результаты, рейтинг, титулы, ачивки
state.js           — состояние активных турниров и заявок на подтверждение (JSON-файлы)
chipStructure.js   — расчёт фишек, блайндов, анте и длин уровней, призовых (чистые функции, без Telegram/БД)
scoring.js         — таблица начисления очков по месту
titles.js          — метаданные динамических титулов и их приоритет
achievements.js    — метаданные разовых ачивок
backup.js          — сборка/восстановление полного бэкапа (свой мини-tar, без зависимостей)
```

Данные не смешаны с кодом: SQLite-база, файлы состояния и `.env` живут только на сервере и никогда не попадают в репозиторий (см. `.gitignore`).

Все даты и время в сообщениях жёстко приведены к московскому часовому поясу (`APP_TIMEZONE` в `index.js`), независимо от того, в каком часовом поясе физически стоит сервер — поменяйте константу, если лига не по Москве.
